# Minimal PDF

Offline, lightweight Android PDF viewer and editor for personal use.

Supports opening PDFs, zoom and navigation, page annotations, page removal, and saving an edited copy. The app has no ads, accounts, analytics, or internet permissions.

## Build

GitHub Actions builds an installable debug APK on each push. Open the latest **Build APK** workflow run and download the `MinimalPDF-APK` artifact.

**Limitation:** Saving edits rasterizes retained pages; text in edited PDFs will not remain selectable. The original is preserved.
